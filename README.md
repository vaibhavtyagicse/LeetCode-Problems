## 💡 Problem-Solving Approach

For each problem, the goal is not just to get an accepted solution.

I focus on understanding:

```text
Problem
   ↓
Understand Constraints
   ↓
Think of Brute Force
   ↓
Find Better Approach
   ↓
Choose Data Structure
   ↓
Optimize Time & Space
   ↓
Implement
   ↓
Test Edge Cases
   ↓
Submit ✅
```

The objective is to gradually move from **brute-force thinking → optimized algorithmic thinking**.
